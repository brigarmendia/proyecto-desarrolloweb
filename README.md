# BL Indumentaria

Sitio web de una tienda de ropa ficticia, desarrollado como proyecto integrador del curso de Desarrollo Web de Coderhouse.

## Páginas

- **Inicio** (`index.html`): presentación, galería de prendas y medios de pago.
- **Productos** (`pages/productos.html`): catálogo de prendas.
- **Nosotros** (`pages/nosotros.html`): historia de la marca.
- **Preguntas frecuentes** (`pages/preguntas.html`): preguntas en formato acordeón.
- **Contacto** (`pages/contacto.html`): formulario de contacto.

## Tecnologías

- HTML5 semántico
- CSS3: Flexbox, CSS Grid, media queries (mobile-first) y pseudoclases
- Bootstrap 5.3: navbar, carousel, modal y acordeón

## Cómo verlo

1. Descargá o cloná el repositorio.
2. Abrí el archivo `index.html` en tu navegador.
